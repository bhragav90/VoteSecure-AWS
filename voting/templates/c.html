About the project

VoteSecure

A student-friendly Django project designed to demonstrate web development, database design, security basics, Git/GitHub and AWS deployment.

Important limitation

This application is not a real election system. It has no government identity integration, no legal election certification, and no guarantee of election-grade security.

For classroom testing, use dummy voter IDs and dummy 12-digit values only.

Security basics

CSRF protection, environment secrets, production settings and one-way identifier hashing.

Cloud learning

Designed for EC2 hosting with optional PostgreSQL on Amazon RDS.

Dev workflow

Git commits, GitHub source control, CI checks and repeatable deployment steps.
